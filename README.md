# LedgeRays Systems website

One-page dashboard-style site built with Bootstrap 5.3 and Chart.js.

## Upload to GitHub
1. Upload everything in this folder (keep the folders: css, js, assets).
2. Repository Settings > Pages > Deploy from branch > main / root.
3. In index.html, set the og:image link to the full URL of assets/og-image.jpg
   so the Facebook link preview shows the image.

## Where to edit
- Text and packages: index.html (each tab is a <section> with id="tab-...")
- Colors: css/style.css (top :root block)
- Sample designs list: js/app.js (array P)
- Sample charts data: js/app.js (sales, target, cats)
